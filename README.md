## ✨ Features

- 🔐 **Secure Login** — SHA256 password hashing
- 📦 **Parts Management** — Add, edit, delete parts with buy/sell pricing
- 📥 **Purchase Tracking** — Record incoming stock
- 📤 **Sales Tracking** — Record outgoing stock with availability check
- 📋 **Transaction Log** — Full history of all purchases and sales
- 🔍 **Live Search** — Filter parts by name or ID in real time
- 🌙 **Modern Dark UI** — Clean, professional dark theme

## 🚀 Getting Started

### Prerequisites
- Python 3.7 or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/SurenaK/warehouse-management.git

# Navigate to the project folder
cd warehouse-management

# Run the app
python main.py
```

> No external libraries needed — runs on Python standard library only.
